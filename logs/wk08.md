For counting you can use the histogram code:
def histogram(s):
    d = {}
    for c in s:
        if c not in d:
            d[c] = 1
        else:
            d[c] += 1
    return d

**OR**

*Tuples are immutable sequences* (signified by () unlike [] for lists)
